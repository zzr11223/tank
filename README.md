# STM32F103ZET6 履带车控制固件

> 文档状态：2026-08-31。当前固件已完成第 0 阶段红外急停锁存、第 1 阶段遥控与编码器控制链，以及第 2B 阶段 IMU 直行航向保持。

## 1. 固件功能

- 采集 6 路接收机 PWM 信号，使用 TIM5 的 1 MHz 计时基准测量高电平脉宽。
- 对每路遥控输入执行 7 点中值滤波，抑制连续尖峰。
- 使用 CH3 控制前进/倒车，使用 CH1 控制转向；转向优先时支持原地差速转向。
- 通过 TIM1 输出左右履带双向 PWM，1500 us 为停止，1000～2000 us 为输出范围。
- 采集 4 路 AB 相编码器并形成左右履带速度反馈。
- 直行时运行左右履带速度同步 PI，自动修正两侧速度差。
- 4 路低电平有效红外输入触发急停锁存；障碍解除后保持停止，CH1、CH3 回中一次并重新推杆后恢复控制。
- USART1 输出四路编码器累计计数，USART3 输出三轴姿态角。
- USART2 接收九轴 IMU 的 `0x26` 欧拉角帧，并记录姿态帧有效状态和更新时间。
- 直行条件下锁定目标 Yaw，使用最短路径航向误差和 PI 控制差速修正左右履带。

## 3. 引脚与外设

### 3.1 遥控器输入

| 通道 | 引脚 | 当前用途 |
|---|---|---|
| CH1 | PA6 | 转向控制与遥测 |
| CH2 | PA2 | 脉宽采集与遥测 |
| CH3 | PA3 | 前进/倒车控制与遥测 |
| CH4 | PA7 | 脉宽采集与遥测 |
| CH5 | PB0 | 脉宽采集与遥测 |
| CH6 | PB1 | 脉宽采集与遥测 |

六路输入均采用 GPIO 双边沿 EXTI 捕获。有效脉宽范围为 1000～2100 us，有效样本进入 7 点中值滤波。

### 3.2 履带 PWM 输出

| 履带 | 定时器通道 | 引脚 | 中位 |
|---|---|---|---:|
| 左履带 | TIM1_CH1 | PE9 | 1500 us |
| 右履带 | TIM1_CH2 | PE11 | 1500 us |

上电初始化时两路 PWM 均从 1500 us 启动。左右履带归属已经通过实车确认。

### 3.3 红外急停输入

| 红外输入 | 引脚 | 极性 | 配置 |
|---|---|---|---|
| IR1 | PC4 | 低电平触发 | 上拉输入 + EXTI |
| IR2 | PC5 | 低电平触发 | 上拉输入 + EXTI |
| IR3 | PC8 | 低电平触发 | 上拉输入 + EXTI |
| IR4 | PC9 | 低电平触发 | 上拉输入 + EXTI |

任一路触发时，左右履带 PWM 立即保持 1500 us，并置位红外急停锁存。障碍解除后，锁存持续保持；CH1 与 CH3 回中一次后解除锁存，随后重新推动摇杆才产生运动命令。

### 3.4 四路编码器

| 编码器 | 定时器 | A/B 相引脚 | 履带归属 | 直行前进原始符号 |
|---|---|---|---|---|
| ENC1 | TIM2 | PA15 / PB3 | 左履带 | 负 |
| ENC2 | TIM3 | PB4 / PB5 | 左履带 | 负 |
| ENC3 | TIM4 | PB6 / PB7 | 右履带 | 正 |
| ENC4 | TIM8 | PC6 / PC7 | 右履带 | 正 |

四个定时器均使用编码器 TI12 正交 x4 计数模式。软件按 16 位计数器回绕规则累计为有符号长期计数，并使用实车标定比例统一四路距离尺度。

### 3.5 串口

| 串口 | 引脚 | 配置 | 功能 |
|---|---|---|---|
| USART1 | PA9 TX | 115200 8N1 | 每 100 ms 输出四路编码器数据 |
| USART2 | PD6 RX（重映射） | 115200 8N1 | 接收 IMU `0x26` 欧拉角帧 |
| USART3 | PB10 TX | 115200 8N1 | 每 20 ms 输出 Yaw、Pitch、Roll |

## 4. 遥控与混控参数

| 参数 | 当前值 |
|---|---:|
| 遥控有效范围 | 1000～2100 us |
| 输出范围 | 1000～2000 us |
| 输出中位 | 1500 us |
| CH1 转向死区 | ±85 us，即 1415～1585 us |
| CH3 油门死区 | ±40 us，即 1460～1540 us |
| 输入滤波 | 7 点中值 |
| 转向方式 | 转向优先、原地差速转向 |

CH3 进入前进/倒车混控，CH1 有效转向命令进入原地差速转向。最终左右命令均钳位在 1000～2000 us。

## 5. 编码器速度同步

直行且油门命令达到门槛时，固件根据左右履带编码器速度差运行 PI，同量反向修正左右 PWM，从而保持平均油门并减小直行速度差。转向时同步 PI 自动复位，由转向混控直接控制两侧履带。

| 参数 | 当前值 |
|---|---:|
| 速度采样周期 | 20 ms |
| 速度低通 | 1/2 一阶滤波 |
| 闭环最小油门 | 60 us |
| 闭环最小平均速度 | 300 counts/s |
| 速度误差死区 | 50 counts/s |
| `Kp` | 0.020 us/(count/s) |
| `Ki` | 0.0015 us/采样 |
| 积分限幅 | ±25000 |
| PWM 修正限幅 | ±60 us |

编码器距离归一化系数为 ENC1=`794/1000`、ENC2=`869/1000`、ENC3=`1013/1000`、ENC4=`988/1000`；右侧速度参考补偿为 `1222/1024`。

## 6. IMU 航向保持

收到有效欧拉角帧后，固件记录最近更新时间；数据年龄不超过 100 ms 时标记为新鲜。CH1 位于转向死区、CH3 命令达到 60 us、红外锁存解除且 IMU 数据新鲜时，固件锁定当前 Yaw 为目标航向，并持续计算 `-180°～180°` 的最短路径误差。

| 参数 | 当前值 |
|---|---:|
| IMU 新鲜度超时 | 100 ms |
| 启动油门门槛 | 60 us |
| 航向 P 系数 | 6 us/° |
| 航向 I 系数 | 2 us/(°·s) |
| 航向误差死区 | ±0.3° |
| 航向积分限幅 | ±24 us |
| 航向修正限幅 | ±60 us |

±0.3° 内的航向误差进入死区，超出死区后进入 PI 计算。积分按实际毫秒累计并限制为 ±24 us，用于学习车辆保持直行所需的固定左右差速；总航向修正限制为 ±60 us，并带输出饱和抗积分累积。航向保持活动时，正修正量增加右履带命令并减少左履带命令；该方向来自实车证据“车辆右偏时 Yaw 减小”。此时编码器等速 PI 自动复位，避免两个闭环互相对抗。人工转向、油门回中、红外锁存或 IMU 超时后退出航向保持，并清除航向积分、恢复原有遥控与编码器控制链。

## 7. 运行顺序

1. 初始化 GPIO、USART、TIM 和 IMU 接收。
2. 将 PE9、PE11 两路履带 PWM 置为 1500 us 并启动输出。
3. 启动六路遥控脉宽捕获与四路编码器计数。
4. 主循环刷新红外状态、IMU 数据、编码器累计值和履带速度。
5. 红外锁存有效时，左右履带保持 1500 us。
6. 红外锁存解除后，CH3/CH1 进入履带混控。
7. 航向保持条件满足时叠加 IMU 差速修正；其余直行状态运行编码器速度同步。
8. USART1 和 USART3 按固定周期发送遥测。

## 8. 串口数据格式

### USART1：编码器数据

每 100 ms 输出一行：

```text
ENC1,ENC2,ENC3,ENC4
```

- `ENC1..ENC4`：四路有符号累计编码器计数。

### USART3：姿态角

每 20 ms 输出一行：

```text
Yaw,Pitch,Roll
```

- `Yaw/Pitch/Roll`：当前欧拉角，单位为度；Yaw 范围为 0～360°。
