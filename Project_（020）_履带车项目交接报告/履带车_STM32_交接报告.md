# 履带车 STM32 已实现功能交接报告

> 更新日期：2026-08-29
> 项目状态：第 0 阶段红外急停锁存与第 1 阶段控制链整理均已完成，并通过真机验收。

## 1. 项目概况

本项目使用 STM32F103ZET6 控制双履带车辆。当前控制链由六路遥控 PWM 输入、双路履带 PWM 输出、四路编码器速度反馈和四路红外急停输入组成；同时保留 IMU 欧拉角接收与姿态串口遥测。

当前固件实现：

- CH3 前进/倒车控制。
- CH1 转向控制与原地差速转向。
- 六路遥控 7 点中值滤波。
- 四路编码器累计计数和左右履带速度测量。
- 直行左右速度同步 PI。
- 红外触发停车、障碍解除后保持停止、回中后重新控制。
- USART1 车辆遥测和 USART3 姿态遥测。

## 3. 引脚与功能映射

### 3.1 遥控输入

| 通道 | 引脚 | 功能 |
|---|---|---|
| CH1 | PA6 | 转向控制与遥测 |
| CH2 | PA2 | 脉宽采集与遥测 |
| CH3 | PA3 | 前进/倒车控制与遥测 |
| CH4 | PA7 | 脉宽采集与遥测 |
| CH5 | PB0 | 脉宽采集与遥测 |
| CH6 | PB1 | 脉宽采集与遥测 |

六路输入通过 GPIO 双边沿 EXTI 捕获，TIM5 提供 1 MHz 计时基准。1000～2100 us 的样本进入 7 点中值滤波。

### 3.2 履带输出

| 履带 | 定时器通道 | 引脚 | 中位 |
|---|---|---|---:|
| 左履带 | TIM1_CH1 | PE9 | 1500 us |
| 右履带 | TIM1_CH2 | PE11 | 1500 us |

输出范围为 1000～2000 us。上电初始化时，两路 PWM 从 1500 us 启动。

### 3.3 编码器

| 编码器 | 定时器 | 引脚 | 履带归属 | 前进原始符号 |
|---|---|---|---|---|
| ENC1 | TIM2 | PA15 / PB3 | 左履带 | 负 |
| ENC2 | TIM3 | PB4 / PB5 | 左履带 | 负 |
| ENC3 | TIM4 | PB6 / PB7 | 右履带 | 正 |
| ENC4 | TIM8 | PC6 / PC7 | 右履带 | 正 |

四路编码器均使用 Encoder TI12 正交 x4 计数。软件处理 16 位计数回绕并形成四个有符号长期累计值。

### 3.4 红外输入

| 输入 | 引脚 | 极性 | 输入方式 |
|---|---|---|---|
| IR1 | PC4 | 低电平触发 | 上拉 + EXTI |
| IR2 | PC5 | 低电平触发 | 上拉 + EXTI |
| IR3 | PC8 | 低电平触发 | 上拉 + EXTI |
| IR4 | PC9 | 低电平触发 | 上拉 + EXTI |

### 3.5 串口

| 串口 | 引脚 | 配置 | 功能 |
|---|---|---|---|
| USART1 | PA9 TX | 115200 8N1 | 车辆 12 列 CSV 遥测 |
| USART2 | PD6 RX（重映射） | 115200 8N1 | 接收 IMU `0x26` 欧拉角帧 |
| USART3 | PB10 TX | 115200 8N1 | 输出 `Yaw,Pitch,Roll` |

## 4. 遥控滤波与履带混控

| 参数 | 当前值 |
|---|---:|
| 遥控有效脉宽 | 1000～2100 us |
| 中值滤波窗口 | 7 点 |
| CH1 转向死区 | ±85 us（1415～1585 us） |
| CH3 油门死区 | ±40 us（1460～1540 us） |
| 履带输出范围 | 1000～2000 us |
| 停止脉宽 | 1500 us |

CH3 生成前进/倒车命令。CH1 进入转向死区外时，转向优先逻辑使左右履带反向输出，实现原地差速转向。所有履带命令在提交 TIM1 前钳位到 1000～2000 us。

## 5. 第 0 阶段：红外急停锁存

第 0 阶段已实现并通过真机验收：

1. 任一路红外输入变为低电平时，立即置位急停锁存。
2. 锁存期间左右履带 PWM 持续保持 1500 us。
3. 障碍解除后继续保持停止。
4. CH1 与 CH3 回中一次后解除锁存。
5. 重新推动摇杆后车辆接受新的运动命令。

红外锁存位于主循环控制优先级最高层，锁存有效时同时复位直行速度同步 PI。

## 6. 第 1 阶段：遥控与编码器控制链

第 1 阶段已实现并通过真机验收：

- 六路接收机 PWM 输入持续采集并经过 7 点中值滤波。
- CH1、CH3 直接形成履带运动命令。
- 四路编码器持续累计并合成为左右履带速度。
- 直行状态运行左右速度同步 PI。
- IMU 欧拉角经 USART3 独立输出姿态遥测。

### 6.1 编码器标定与速度计算

| 编码器 | 距离归一化系数 |
|---|---:|
| ENC1 | `794/1000` |
| ENC2 | `869/1000` |
| ENC3 | `1013/1000` |
| ENC4 | `988/1000` |

左右速度每 20 ms 更新一次，并使用 1/2 一阶低通。右侧参考补偿系数为 `1222/1024`。

### 6.2 直行速度同步 PI

| 参数 | 当前值 |
|---|---:|
| 最小油门命令 | 60 us |
| 最小平均速度 | 300 counts/s |
| 速度误差死区 | 50 counts/s |
| `Kp` | 0.020 us/(count/s) |
| `Ki` | 0.0015 us/采样 |
| 积分限幅 | ±25000 |
| PWM 修正限幅 | ±60 us |

直行时，PI 根据左右履带速度差生成修正量，并对左右 PWM 等量反向叠加。转向时 PI 自动复位，由差速转向直接控制履带。

## 7. 遥测格式

### 7.1 USART1 车辆遥测

USART1 每 100 ms 输出：

```text
CH1,CH2,CH3,CH4,CH5,CH6,LPWM,RPWM,ENC1,ENC2,ENC3,ENC4
```

- `CH1..CH6`：滤波后的接收机脉宽，单位 us。
- `LPWM/RPWM`：实际提交给左右履带控制器的脉宽，单位 us。
- `ENC1..ENC4`：四路有符号累计编码器计数。

### 7.2 USART3 姿态遥测

USART3 每 20 ms 输出：

```text
Yaw,Pitch,Roll
```

三个角度保留两位小数，Yaw 范围为 0～360°。
